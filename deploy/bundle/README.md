# asset join bundle

Generated by the gateway (Gateway operations › Modules › asset › Add).

    docker compose up -d

The bundle runs asset with its own TimescaleDB (`asset-db`), Valkey event bus
(`asset-valkey`) and RustFS object store (`asset-s3`), all over TLS from the
bundle's local CA. Inventory-sync, paperless document storage and the
platform scheduler's `asset:inventory-sync` task are off: those services run
on other hosts and are not in this bundle's discovery.

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds generated passwords and the KEK. Keep both on this
host only. The enrolment token is valid for the lifetime chosen in the
wizard; after the first start the module renews its identity itself.
