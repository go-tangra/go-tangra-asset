# asset join bundle

Generated by the gateway (Gateway operations › Modules › asset › Add).

    docker compose up -d

The bundle runs asset with its own TimescaleDB (`asset-db`) and RustFS object
store (`asset-s3`), both over TLS from the bundle's local CA. Inventory-sync,
paperless document storage and the platform scheduler's
`asset:inventory-sync` task are off: those services run on other hosts and
are not in this bundle's discovery.

asset joins the core's event bus (Valkey, TLS) as user `asset`: its realtime
events reach the browser through the gateway, which reads them from the
core's Valkey. The core's Valkey must accept the ACL user `asset` from this
host; give its address, password and CA certificate file in the wizard.

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds generated passwords and the KEK; `config.yaml` holds
the event-bus password you gave. Keep them on this host only. The enrolment
token is valid for the lifetime chosen in the wizard; after the first start
the module renews its identity itself.
